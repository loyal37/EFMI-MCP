- **本机配置**：ZZMI `d3dx.ini` 的 target 为 `ZenlessZoneZero.exe`，shader_hash=3dmigoto、texture_hash=0、**track_region_hashes=0**；当前服务的 IB／VB 主 hash 使用绘制区域 CRC，同时另存 resource_hash。因此 ZZMI 的 INI 哈希与自动匹配需要按整资源口径适配，不能直接拿 EFMI 的区域 hash 写进去。安装扫描入口已执行，可读 Include／exclude 规则，本目录扫描到 0 个活动 mod／0 个引用 hash（不能据此验证非空模组匹配）。

- 随后解释了“区域 hash”：对缓冲内按偏移和长度选出的一段字节算 CRC32C，用于区分共享大缓冲里的网格；不是屏幕区域。IB 范围由绑定偏移、first_index、index_count 和索引宽度决定；VB 对 indexed draw 按 XXMI 规则估算范围，不能当全网格逐字节验证。ZZMI 的哈希匹配口径与能否读取原始资源是两个问题，未要求开启其区域哈希或修改代码。

## RabbitFX 写法的角色头发粗描边：原因已查明（2026-10-09 下午，真实游戏 PID 12176；只读，另按 F11 两次做对照）

- 用户报告：“使用 rabbitfx 标记贴图的角色的头发会有一层厚厚的描边……当前屏幕的角色就有这个问题”。屏上是 `Typhoeus Luxuria 1.2 alpha`（`Typhoeus.ini`，头发是 Component1 `ddc92b8b-54816-0`，贴图经 `Resource\RabbitFx\Diffuse|LightMap|NormalMap` 交给 RabbitFX）。本轮没有改任何文件，只读取并做了一次 F11 关／开对照。
- **结论**：描边没有变粗，是大部分没上色。头发的描边是外扩外壳（VS `f3b955247775c7bf`，剔除正面），分两步画：预写遍写深度并把颜色写成黑；上色遍在深度相等处把黑盖成“漫反射 × 0.45”的深色。RabbitFX 2.7 的 `[ShaderRegexMain.Pattern]` 把匹配到的着色器里第一个二维贴图采样当作漫反射（换成 `t70`），其后 20 行内的下一个 `sample_b` 当作法线（换成 `t72`）。头发描边上色着色器的第一个采样是透明度测试用的遮罩（只取 R，阈值 0.5），第二个才是漫反射。于是绑了 RabbitFX 贴图后：透明度测试拿 mod 漫反射的 R 去比 0.5，描边颜色取自 mod 的法线贴图。预写遍不受影响，整圈外壳照常写黑；上色遍只在漫反射线性 R ≥ 0.5（存储值 ≥ 188/255）处画上，其余留下预写遍的黑，画上的地方颜色也不对。
- **三遍与哈希**（探针报的是改写后字节码的哈希，括号里是 XXMI 的原始哈希）：预写遍 PS `1727997065f66ff9`（`31e969822a004ce4`，RabbitFX 的 SimpleHairShadow：`t73` 绑了才用，否则 `t0`，认得对）；上色遍 PS `7888f0e738bb6538`（`fadc3687dd18e11c`，认错的就是它）；另一上色变体 PS `be674f7036a71570`（`5142344131771c57`，第一个采样就是漫反射，认得对）。本角色头发自己的 G-buffer 着色器 `00cf31fc5c40c10d` 也认得对（`t73`／`t70`／`t72`）。
- **证据**（都在被忽略的 `captures/rabbitfx-hair-outline-20261009/` 和 `captures/shaders/`）：
  - 反汇编：改写后 `7888f0e738bb6538-ps.asm` 第 89–94 行（`t70` 否则 `t14`，只取 R）、170–172 行（减 `cb6[12].x` 后 `discard`）、182–186 行（`t72` 否则 `t13`，随后乘色调、调饱和度，是底色）；改写前 `fadc3687dd18e11c-ps.asm` 第 74–77、87 行。
  - 用 RabbitFX 自己的匹配式离线重放（`replay_main_pattern.py`，改写前的列表取自探针）：`diffuse` 落在第 74 行（`t14` 遮罩），`normalmap` 落在第 87 行（`t13` 漫反射）。
  - 常量：上色遍 `ps-cb6[12].x = 0.5`、`cb6[13].z = 0.45`；预写遍 `ps-cb1[12].x = 0.5`。
  - 按头发 15306 个顶点的 UV 取贴图（`hair_uv_stats.py`）：游戏遮罩 `240a4029` 的 R ≥ 0.5 的占 98.7%；mod 漫反射 `0409102f`（与游戏的 `637eee72` 是同一张图）线性 R ≥ 0.5 的只占 15.4%。
